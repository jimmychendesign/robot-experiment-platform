# Archived PRDs

This directory contains PRDs whose inactive status has been explicitly confirmed.

Valid archive statuses are:

- `Superseded`
- `Cancelled`
- `Obsolete`

Do not archive a PRD merely because it is implemented, validated, old, inactive, or inconsistent with current code. Archive moves require explicit user confirmation or an existing confirmed product decision.

Use year-based folders such as `archive/2026/`. Preserve archived content as historical evidence and record successor relationships in the root [PRD Registry](../README.md).
